# Original interface refinement

The original black-and-violet interface at `c8baa61` is the visual reference. The `feat/original-refined` branch starts there and merges the current functional fixes before refining the UI.

Keep the floating desktop navigation, prominent full-proportion artwork, quiet metadata and compact controls. Use midnight black (#08080c), raised black (#111116), violet (#a395ff), near-white (#f4f3fa), readable muted text (#9592a7) and gold (#f1c875). Outfit is locally hosted with swap; headings use the same proportional family. Violet identifies actions, gold identifies ratings.

Retain the journal/grid switch, native personal rating selectors, real collection shelf, single-call enrichment, guarded episode changes, sync ordering, public navigation and offline shell. Detail pages use a complete 2:3 poster beside the title on every viewport. The tracking section spans the mobile width and keeps progress separate from ratings. Status menus and external links have comfortable touch areas.

Use isolated production-browser checks at 320, 390, 820 and 1440px. Inspect screenshots, test saved edits and actual status menu clicks, then verify real offline navigation. No deployed PageSpeed or live deployment result is implied by local validation.
